# Gerador-de-senhas-
## Funcionalidades:
-Geração instantânea de senhas;
-Escolha do números caracteres (4 a 32);
-Inclusão de: Letra maiúscula, Letra minúscula, Símbololos e Números
-Bara indicativa da força da senha;
-Interface resonsiva;
-Atualização automática da senha sempre que uma configuração é alterada.

## Responsividade
-O projeto foi desenvolvido para funcionar em diferentes tamanhos de tela, oferecendo uma boa experiência tanto em computadores, tanto em dispositivos móveis.

## Objetivos do projeto
-Este projeto foi desenvolvido com fins educacionais para praticar conceitos de desenvolvimento front-end, incluindo:
-Eventos em JavaScript;
-Organização de código
-Geração aleatoria de caracteres
-Responsividade com CSS
